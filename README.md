# Little Shrimp Canteen｜小虾食堂

Little Shrimp Canteen 是一款面向情侣和小家庭的私人餐桌 App。它把散落在小红书、相册和其他平台的菜谱，转化成可执行的菜单、采购清单和做菜记录，帮助两个人一起决定吃什么、买什么、花多少，并保存每一次开饭的共同记忆。

> 像逛商店一样挑菜，一键算出这周吃什么、买什么、花多少，再把一起做饭的日子好好保存下来。

## 核心闭环

```text
发现菜谱 → AI 导入 → 菜谱仓库 → 加入菜单篮 → AI 配餐检查
         → 采购清单 → 共同采购与记账 → 做菜 → 点评与分享
```

## 核心能力

- **AI 菜谱导入**：上传小红书截图或其他菜谱图片，自动识别菜名、食材、用量和步骤，并保留原始来源。
- **私人菜谱仓库**：保存想做、喜欢和做过的菜，根据时间、口味、食材和两个人的偏好筛选。
- **菜单篮**：像购物一样选择明天或本周要做的菜，并设置日期、餐次、人数和食量。
- **AI 配餐检查**：在结算前检查菜量、荤素搭配、蔬菜、蛋白质、热量和烹饪时间，并给出可执行的调整建议。
- **智能采购清单**：按人数换算和合并食材，标记家里已有、待购买、没找到和已买到。
- **共同采购与记账**：边买边勾选，临时添加零食或日用品，记录实际数量、金额、付款人以及计划内和计划外消费。
- **做菜记录与点评**：为每次制作保存照片、双人评分、实际调整和下次改进，观察同一道菜的复做变化。
- **拍摄与分享**：提供构图引导、自然优化和餐桌分享模板，让普通家常菜也能留下好看的记录。

## 产品定位

Little Shrimp Canteen 不是公开菜谱社区，也不是通用记账或减重软件。它首先是两个人共同维护的私人餐桌：

- 小红书和菜谱平台负责带来灵感，Little Shrimp Canteen 负责把灵感变成实际行动。
- 健康功能用于温和地改善一顿饭和一周菜单，不提供医疗诊断。
- 记账聚焦餐桌相关采购，不扩展到完整个人财务。
- AI 用于减少整理和计算，但结果始终可以确认、编辑和撤销。
- 真实照片和共同经历比完美的商业食品图更重要。

## 视觉方向

主风格为：

> **Headspace 式温暖亲和 × 私人餐桌手账**

整体追求治愈、温暖、松弛、可爱但不幼稚。真实食物照片是主角，清晰工具界面构成骨架，小锅、小碗、菜篮和食材等原创简笔角色负责情绪表达。

建议视觉比例：

- 70% 暖手账与清晰工具界面。
- 20% 安静的食谱编辑与真实摄影。
- 10% 简笔漫画和情绪惊喜。

## 建议的下一步

优先制作三组移动端界面：

1. **餐桌首页与本周菜单**：验证品牌温度和核心入口。
2. **菜单 AI 结算与采购清单**：验证最关键的工具闭环。
3. **做菜记录与分享卡片**：验证长期记录和情感价值。

原型验证完成后，再确定前端形态、AI 服务、营养数据来源和双人实时同步方案。

## MVP 原则

- 先让用户把收藏的菜真正做出来，再增加更多发现能力。
- 优先跑通“导入—菜单—采购—做菜记录”，避免第一版范围失控。
- 截图识别优先，小红书链接主要用于保留出处。
- 所有营养数据均为估算，并允许用户修改关键用量。
- 公开社区、复杂库存、通用记账和生成式食物重绘不进入第一阶段。

## 北极星指标

> 每个餐桌空间每周完成的“从菜单到做菜记录”的闭环次数。
