# 设计参考资源

> 用于 Little Shrimp Canteen 静态设计稿、真实产品界面和视觉方向调研。

做 App 静态设计稿时，建议优先看 Mobbin、Refero 和 Behance。前两个适合研究真实产品界面与流程，Behance 适合寻找完整的视觉方向。

| 网站 | 适合看什么 | 使用建议 |
| --- | --- | --- |
| [Mobbin](https://mobbin.com/) | 已上线 App、网站的界面和流程 | 优先研究首页、列表、详情页怎样组织信息。 |
| [Refero](https://refero.design/) | Web、iOS 界面参考 | 带着具体问题搜索，例如搜索、筛选和内容详情如何布局。参见 [How it works](https://refero.design/how-it-works)。 |
| [Behance](https://www.behance.net/galleries/ui-ux) | 完整项目、品牌与 UI 设计 | 观察一套设计如何通过字体、照片与颜色形成统一风格。 |
| [Dribbble](https://dribbble.com/search/ui-design) | 单屏 UI、视觉细节 | 适合寻找局部灵感，不直接照搬整套产品结构。 |
| [Godly](https://godly.design/) | 精选网页、App 和视觉设计 | 用于拓宽视觉风格，探索常规组件之外的表达。 |
| [Awwwards](https://www.awwwards.com/) | 网站设计与交互作品 | 更适合研究品牌官网和专题页。 |

## 建议使用顺序

1. 在 Mobbin、Refero 中确认真实产品的信息架构和交互惯例。
2. 在 Behance 中寻找完整、统一的品牌与视觉方向。
3. 在 Dribbble 中补充卡片、导航、摄影等局部细节。
4. 在 Godly、Awwwards 中拓宽品牌表达和交互灵感。
